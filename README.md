# Customizable-X-ray-Bedrock
In the name.
It is an application that you install. Once installed, you can edit the visible or invisible blocks and build the pack to then import into minecraft. Once in, it's pretty self-explanatory. Really useful, client-side, and able to be used on very large servers wqithout being detected as it is custom.
Double-click on the download in your browser, then in files double-click on "Install X-tra X-ray"
